# 投稿ページ(post.html)のセットアップ手順

部会の方がログイン不要で投稿できるページです。最初に1回だけ、次の作業をします。

## しくみ（なぜ2つのスプレッドシートを使うか）
サイト用スプレッドシートは「リンクを知っている全員が閲覧可」で、そのIDはサイトのソースにも載っています。
そこに確認前の投稿（本文・写真のリンク）を入れると、表示されなくても誰でも読めてしまいます。
そのため、次のように分けます。

1. 投稿 → **非公開**スプレッドシートの「投稿受付」タブに入り、写真・PDFも**非公開**のDriveフォルダに保存される
2. 役員が内容を確認し、「投稿受付」の公開列を **「公開する」**（または **「却下」**）に変える
3. 5分以内に自動で、承認分だけがサイト用スプレッドシートにコピーされ、ファイルが閲覧可になる（却下分のファイルはゴミ箱へ）

## 0. アカウント
個人のアカウントではなく、**協議会用のGoogleアカウント**で作業するのがおすすめです（担当交代で消えないため）。
そのアカウントは **2段階認証を有効**にしてください。投稿の受け口はこのアカウントの権限で動きます。

## 1. 準備
1. Google ドライブに、添付ファイルの保存用フォルダを作る（例:「春日校区サイト添付」）。**共有設定はしない（非公開のまま）**。
   開いたときのURL `https://drive.google.com/drive/folders/【ここ】` の部分がフォルダID。
2. **非公開用スプレッドシート**を、サイト用とは別に新規作成する（共有しない）。
   - タブ「合言葉」: A列=組織名、B列=合言葉。組織名は `organizations.html` の表記と同じにする（例:「高田２丁目自治会」は全角の２）。
   - タブ「投稿受付」: 1行目に見出しを入れる
     `タイムスタンプ / 組織名 / 公開日 / カテゴリ / タイトル / 内容 / 添付ファイル / 公開 / 処理結果`
3. サイト用スプレッドシートのIDを控える（`/d/【ここ】/edit` の部分）。

### 合言葉の決め方
- **8文字以上**にする。数字4桁などは不可（例: 「さくら-みかん-2026」のような言葉の組み合わせ）。
- 部会ごとに別のものにし、メンバーが変わったら変更する。
- 間違いが5回続くと、その組織は10分間投稿できなくなる（総当たり対策）。

## 2. Apps Script を作る
1. **非公開用スプレッドシート**を開く → 拡張機能 → Apps Script。
2. `apps-script/Code.gs` の内容を貼り付け、`FOLDER_ID` と `SITE_SS_ID` を入れる。
3. 関数 `setupTriggers` を選んで **実行**（5分おきの自動公開が設定される）。初回は権限の承認画面が出るので承認する。
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 表示された「ウェブアプリのURL」をコピーする。

## 3. サイトにつなぐ
`js/config.js` の `POST_ENDPOINT` にURLを貼り、コミットして公開する。

## 4. 運用
- **確認のとき必ず見るもの**: 写真・PDFに、個人の電話番号・住所・氏名、子どもの顔などが写っていないか。
  問題があれば公開列を「却下」にする（ファイルはゴミ箱に移る）。
- 公開後に取り下げたいときは、サイト用スプレッドシート「組織お知らせ」の公開列を「公開する」以外にする。
  ファイルも閲覧不可にしたい場合は、Driveで共有を解除するか削除する。
- Code.gs を直したら「デプロイを管理」→ 編集 → 新バージョン、で再デプロイする（URLは変わらない）。

## 5. 部会へのURL配布
リンクは公開ページに載せない運用。LINEやチラシのQRコードで配る。
- 共通: `https://hirakata-kasuga.github.io/post.html`
- 部会ごと（部会が選択済みになる）: `https://hirakata-kasuga.github.io/post.html?org=老人会`

`post.html` は `noindex` 付きで、`sitemap.xml` にも載せていません。ただし**URLを知っていれば誰でも開ける**ため、
実際の防御は合言葉と、公開前の確認です。

## 部会への案内に入れてほしいこと
- 写真は、資料だけを撮る（人の顔・車のナンバー・名簿などを入れない）
- 個人の電話番号・住所・メールアドレスは載せない
- 合言葉は部会の外に教えない
